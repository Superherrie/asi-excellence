Setup Required

ASI Excellence needs to be connected to your Supabase project before it can be used.

  1. Open your Supabase project → SQL Editor → New query.
  2. Paste and run the contents of supabase-setup.sql.
  3. In the Supabase dashboard, go to Authentication → Providers → Email and turn off "Confirm email".
  4. Copy config.example.js to config.js and fill in your Project URL and anon key (from Project Settings → API).
  5. Bootstrap your first admin by running this in the Supabase SQL editor (replace the values): 
    insert into public.pending_invites (email, name, app_role)
values ('your.email@asi.co.za', 'Your Name', 'admin');
  6. Reload this page and sign up with that email.
